# Пятый тайм

Локальная панель карьеры EA SPORTS FC 26 для Windows.

1. Откройте `Launch.cmd`. При первом запуске на другом компьютере установите Node.js 24 или новее и выполните `npm ci` в папке приложения.
2. Запустите FC 26 в оконном режиме без рамки. `F10` показывает и скрывает панель. После закрытия окна панель остаётся в системном трее.
3. По умолчанию панель ищет последний сейв в `%LOCALAPPDATA%\EA SPORTS FC 26\settings`. Кнопка «Подключить сейв» закрепляет выбранный файл. «Найти последний сейв» возвращает автоматический выбор.

`Launch-FC26.cmd` запускает панель и открывает FC 26 выбранным способом. При появлении окна игры панель открывает «Следующий матч» подключённой карьеры. В разделе «Связь с EA SPORTS FC 26» можно выбрать `FC26.exe`, ярлык Windows или ярлык Steam. Для запуска игры отдельно можно включить запуск панели в трее вместе с Windows. На экране матча есть форма команд, прогноз, пробная симуляция и кнопка возврата в окно игры. Симуляция выполняется в панели. Результаты сыгранных в FC 26 матчей обновляются после записи сейва.

На главной странице можно продвигать календарь на день или до матча, редактировать стартовый состав и симулировать матчи с отчётами, новостями и таблицами. Прогресс, сообщения и переговоры сохраняются локально для карьеры и сезона. В «Трансферах» есть состав, список продажи и предложения с модельными ответами. «Новости» включают события карьеры и футбольную RSS-ленту BBC Sport.

При подключённом сейве режим «Карьера FC 26» показывает дату из игры. Открой карьеру в оконном режиме без рамки и выбери «Управление FC 26». Для каждого действия нажми «Записать», в игре наведи курсор на текст нужной кнопки и нажми `F8`. Панель выполняет клик по этой кнопке, когда окно и участок экрана совпадают с записанными. Открывай соответствующее меню FC 26 перед отправкой команды. Если Windows не передала фокус, панель предложит переключиться через Alt + Tab и подтвердить действие через `F9`. После записи сейва панель обновляет дату и открывает карточку сыгранного матча.

На поле панели можно выбрать игрока для любой позиции. Кнопка «Состав в FC 26» открывает игровое меню после привязки. План состава и предложения можно скопировать, а изменения в составе и сделках подтверждаются в меню игры. Режим «Симуляция панели» хранит собственные результаты. Пасы и обводки с символом `≈` рассчитаны по минутам, оценкам, позиции и атрибутам. Фактические данные видны рядом или в секции импорта.

На карточке игрока можно прикрепить фото и скачать карточку со статистикой в PNG. В настройках доступны деморежимы карьеры тренера и игрока, когда сейв ещё не подключён.

В «Мировой статистике» можно выбрать турнир, клубы или сборные, отсортировать игроков по голам, ассистам, оценке и показателям за 90 минут. Для сравнения удельных показателей учитываются игроки от 270 минут. Для рейтинга по оценке также требуется минимум три матча с оценкой. Результаты небольших выборок приближаются к средней оценке по выбранному турниру или набору турниров. Рейтинг силы команд рассчитывается по методу Эло на основе ОВР и результатов видимых в сейве матчей. У каждого турнира видны количество сыгранных встреч и наличие статистики игроков.

«Гол + пас» есть в мировых рейтингах, турнирах и профиле футболиста. «Вся карьера» в профиле объединяет доступные архивные сезоны и показывает итог и разбивку по сезонам, командам и турнирам, в которых игрок выходил на поле. История клуба хранит состав, схему, матчи и трофеи, когда эти поля есть в сохранении. В «Истории сезонов» можно добавить старые сейвы той же карьеры. При автоматическом обнаружении разные слоты объединяются при совпадении идентичности карьеры и нескольких результатов.

«Академия» включает воспитанников своей команды и отдельный рейтинг талантов других клубов U21. В нём можно выбрать клуб, турнир и сортировку по потенциалу, ОВР или матчевой статистике. Список U21 строится из зарегистрированных клубных составов, которые есть в сейве.

В «Матчах → Все команды» можно выбрать турнир, клуб, месяц и сезон. Проценты исходов и шансы на титул рассчитывает панель по сохранённым результатам и рейтингам. Еврокубки открываются на Лиге чемпионов. Для остальных турниров кнопка «Этапы и шансы» находится в карточке соревнования. Рейтинги наград раскрываются до 30 игроков при достаточном количестве кандидатов. Игровые записи и расчётные подборки по неделям, месяцам и годам отображаются отдельно. «Слухи панели» в трансферном радаре основаны на сроках контрактов и оценке возможного усиления.

Дополнительные показатели можно импортировать в карточке сыгранного матча. Поддерживаются CSV, TSV и JSON с игровым `playerId` и полями `passes`, `completedPasses`, `dribbles`, `completedDribbles`, `shots`, `shotsOnTarget`, `tackles`, `xg` и `xa`. `teamId` помогает точно отнести запись к команде. Пример строки CSV — `playerId,teamId,passes,completedPasses,dribbles`. В JSON можно передать массив объектов или массив `players`. Рейтинги помечают показатели импорта и учитывают матчи с импортированными данными.

Портреты лицензированных игроков и эмблемы загружаются по игровым ID из публичных источников EA и сохраняются локально. В «Настройки → Портреты и эмблемы» можно выбрать папку с локальным экспортом из FIFA Editor Tool или с уже экспортированными ресурсами игры. Панель распознаёт `p<id>` для портретов и `l<id>` для эмблем, в форматах PNG, JPG, WebP и DDS DXT1/3/5. При совпадении ID локальный экспорт имеет приоритет. Для вымышленных игроков без изображения из экспорта используются инициалы или вручную прикреплённое фото.

Статистика обновляется после записи сейва. Архив сохраняет сезоны по мере чтения выбранного файла. Для таблиц некоторых турниров правила при равенстве очков могут отличаться от игры. Записи индивидуальных наград с неизвестным кодом остаются видны в таком виде. «Прогноз» показывает расчёт приложения. Папка игры и исходные сейвы открываются только на чтение.

## Проверка

`npm test` запускает проверки расчётов и преобразования данных. `npm start -- --verify` проверяет основные сценарии интерфейса. Дополнительно `FC26_VERIFY_SAVE` принимает путь к сейву для проверки импорта в отдельном профиле.

## Источники

Чтение сейвов использует [eafc-db-kit](https://github.com/ViniMacacari/eafc-db-kit). Шрифт Golos Text распространяется по лицензии OFL в папке `ui/assets`. Изображения `pitch.png`, `euro-cup.png` и `portraits.png` созданы встроенным ImageGen. Запросы описывали выход вымышленного нападающего № 9 на ночное поле в графитово-зелёном свете, оригинальный серебряный кубок в холодном свете стадиона и сетку из восьми студийных портретов вымышленных футболистов.
