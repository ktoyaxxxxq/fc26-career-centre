# Пятый тайм — передача проекта

Это настольная панель карьеры EA SPORTS FC 26 для Windows. Пользователь начинает с экрана штаба и хочет вести карьеру тренера или игрока из одного места. Главный приоритет доработки — надёжно передавать действия в запущенную FC 26, подтверждать прогресс по сейву и возвращать пользователя к отчёту.

## Локальный запуск

1. Распакуй папку целиком. Для разработки используй Windows x64 и Node.js 24 LTS.
2. В корне выполни `npm ci` и `npm start`. Для первой установки нужна сеть. Дальше можно открывать `Launch.cmd`.
3. Панель запускается с демоданными. Примеры интерфейса находятся в [references](references). Для проверки реального импорта подключи собственный сейв карьеры FC 26.

`npm test` проверяет доменные расчёты. `npm start -- --verify` прогоняет сценарии интерфейса в отдельном тестовом профиле. Для проверки на своём сейве в PowerShell задай `$env:FC26_VERIFY_SAVE` абсолютным путём к файлу перед запуском проверки. `npm start -- --verify-overlay` проверяет регистрацию F10, открытие окна и сворачивание панели. Для гарантии свободной глобальной F10 закрой рабочий экземпляр перед этим тестом.

## Что уже есть

- Штаб карьеры, календарь, день матча, интерактивное поле с позициями, прогноз, отчёт, история сезонов, внутриигровая лента, мировая RSS-лента BBC Sport, сообщения и трансферный центр.
- Профили игроков и клубов, награды, сборные, рейтинги, еврокубки, рейтинг U21 и академия своего клуба. По другим клубам U21 берётся из зарегистрированных составов. Женские игроки и связанные записи фильтруются до показа, включая старые архивы.
- В локальной симуляции можно продвигать календарь, выбирать состав, получать спроектированные результаты, статистику, сообщения и ответы на трансферные предложения. Режим из сейва показывает фактическую дату. Прогресс сценария хранится по карьере и сезону.
- Рейтинги учитывают объём выборки, а показатели пасов и обводок, оценённые моделью, имеют метку ≈. Сохранённые и импортированные показатели отображаются с собственным источником.

## Как устроен код

| Файлы | Назначение |
| --- | --- |
| `desktop.cjs`, `preload.cjs` | Electron, окно и трей, IPC, опрос сохранений, глобальные клавиши |
| `save-worker.mjs`, `ui/core.mjs`, `ui/men-career.mjs`, `ui/archive.mjs` | Чтение сейвов через eafc-db-kit, модель данных, фильтр игроков, запись архивов панели |
| `ui/app.mjs`, `ui/desk-views.mjs`, `ui/style.css` | Навигация, штаб, поле состава, отчёты и остальной интерфейс |
| `ui/season-sim.mjs`, `ui/desk-market.mjs`, `ui/desk-store.mjs` | Симуляция матчей и календаря, сделки по модели, состояние сценария в IndexedDB |
| `ui/world.mjs`, `ui/estimate.mjs`, `ui/telemetry.mjs` | Рейтинги и статистика из сейва, оценки по модели, импорт отдельных послематчевых данных |
| `game-link.cjs`, `game-control.cjs`, `game-control.ps1` | Обнаружение окна FC 26, фокус и привязка кнопок нативными средствами Windows |
| `verify-ui.cjs`, `*.test.mjs`, `*.test.cjs` | Сценарии проверки интерфейса и расчётов |

Сейв является источником фактического результата. Опрос файла идёт в основном процессе, декодирование выполняет worker, интерфейс получает обновлённые данные через IPC. Исходный сейв используется в режиме чтения. Архивы и настройки лежат в каталоге `app.getPath('userData')`, сценарии отдельно в IndexedDB. Ассеты интерфейса находятся в `ui/assets`.

## Что проверять и дорабатывать первым

1. Пользователь запускает игру через FIFA Mod Manager с Live Editor. Проверь связку именно на его обычном сценарии и с включённым оконным режимом без рамки. F10 управляет панелью, F8 записывает положение и визуальный образ выбранной кнопки, F9 подтверждает команду после Alt+Tab, если Windows не передала фокус.
2. Прогони в реально запущенной игре переход на день, переход до матча, начало матча и игровую симуляцию. Текущая реализация нажимает записанную кнопку на совпадающем экране. Изменение даты или открытие отчёта подтверждается обновлённым сейвом, иногда после ручного сохранения. Проверь смену файла, полноэкранный режим, разный масштаб Windows и окно повышенного уровня прав.
3. Приоритет продукта — удобные переходы между игровыми экранами и применение состава. Сейчас поле сохраняет план, а игровые правки состава, переговоры и выбор конкретных меню выполняются в FC 26. Если добавишь полноценную связь, показывай подтверждённое состояние игры и корректно обрабатывай несовпадение процесса, экрана, активной карьеры или даты.
4. Сохраняй разделение показателей из сейва и модели. Проверь архив нескольких сезонов, прогресс сценария после перезапуска и отсутствие женских игровых записей в новых представлениях.

До передачи прошли 36 автоматических тестов и настольный прогон на сейве карьеры тренера. Отдельно проверили разбор файла после распаковки полной сборки. Реальное нажатие кнопок в окне FC 26 остаётся главным ручным сценарием QA. Приложение рассчитано на внешний интерфейс Windows и чтение локальных сохранений.
